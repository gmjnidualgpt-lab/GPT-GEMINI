GPT-GEMINI / TriadBridge

Projekt integracji GPT, Google Gemini, Cloudflare i Supabase.

Cele

- Integracja modeli GPT i Gemini przez API.
- Cloudflare Workers jako bezpieczna warstwa pośrednicząca.
- Supabase jako baza danych.
- GitHub jako repozytorium kodu i automatyzacji wdrożeń.
